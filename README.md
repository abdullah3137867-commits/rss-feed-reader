# RSS Feed Reader

A React application that fetches and displays RSS feed items from Haris Subandie's blog.

## Features

- 📰 Display RSS feed items
- 🎨 Modern UI with gradient styling
- 📅 Formatted dates
- 🏷️ Category tags
- 🔄 Refresh functionality

## Getting Started

### Installation

```bash
npm install
```

### Start Development

```bash
npm start
```

The app will open at `http://localhost:3000`

## Available Scripts

- `npm start` - Run development server
- `npm build` - Build for production
- `npm test` - Run tests

## Technologies

- React 18
- CSS3
- Fetch API
- XML Parsing
